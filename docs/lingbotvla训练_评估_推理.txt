编写配置文件：
config/robot_configs/soarm101.yaml 机器人本体配置文件，参考lingbotvla\data\vla_data\README.md
config/vla/tmy_test_finetune.yaml  训练配置文件  参考configs\vla\Training_Config.md

把所需模型预训练权重(qwen2.5VL、lingbotvla-4b)、数据集放到数据盘: /root/autodl-tmp/下
环境配置（不带深度）（AutoDL）：
conda init bash && source /root/.bashrc  # 更新bashrc中的环境变量
conda create -n lingbotvla python=3.12.3    
conda activate lingbotvla  # 切换到创建的虚拟环境：lingbotvla
bash install.sh （若换行不能识别，则需要dos2unix）
安装ffmpeg：apt-get install -y ffmpeg

以下需要显卡：
生成归一化文件：
apt-get update && apt-get install -y dos2unix
dos2unix train.sh
chmod +x train.sh
CUDA_VISIBLE_DEVICES=0 bash train.sh scripts/compute_norm.py ./configs/vla/tmy_test_finetune.yaml --data.data_name soarm101 --data.train_path /root/autodl-tmp/SOARM101_redcard --data.norm_stats_file assets/norm_stats/tmy_test_finetune.json

确认pip中有了：
lerobot、lingbotvla、cuda版本的torch、flash-attn，以及服务器中有ffmpeg(which ffmpeg)后，可以开始训练
