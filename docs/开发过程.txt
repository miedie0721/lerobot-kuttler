环境配置（以下是linux教程，windows教程略）：
下载miniconda并配置conda源和pip源、创建虚拟环境：
sudo apt update && sudo apt upgrade -y
若太慢则换源，参考：https://mirrors.tuna.tsinghua.edu.cn/help/ubuntu/
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/.bashrc
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --set show_channel_urls yes
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
conda create -n leorbot060 python=3.12.13
conda activate lerobot060

激活miniconda（如果命令前面有base了就不需要）：
source ~/miniconda3/bin/activate
激活虚拟环境：
conda activate lerobot060

下载依赖：
conda install ffmpeg -c conda-forge
pip install -e ".[feetech]"    # 直接以二次开发模式安装依赖，先安装feetech的，后续需要指定模型的时候再用pip install -e ".[指定toml依赖变量]"补充就是。
其他要下载的（位于pyproject.toml）：pip install -e ".[hardware, core_scripts,kinematics,dataset]"
例如要补充toml文件中的变量名为dataset的依赖，则：pip install -e ".[dataset]"
由于我们会专注于二次开发，所以要pip install -e ".[dataset]"的方式来安装依赖，切勿pip install 'lerobot[dataset]'
此时默认安装的是cpu版本的torch，再次安装cuda版本的torch进行覆盖（cu128 + torch-2.11.0）：
pip install torch==2.11.0 torchvision==0.26.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cu128
若下载速度太慢，可以先下载离线包，再pip install 3个离线包，离线包地址：https://download.pytorch.org/whl/torch/
